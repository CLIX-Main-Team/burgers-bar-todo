# agents — operating instructions

Working rules for the engineering agents in this repo — how to track work, how to triage, and how
to consume the domain docs. These are operating instructions, not product documentation. AGENTS.md
at the repo root points here.

Documents:

- issue-tracker.md — issues and PRDs live as GitHub issues; the gh CLI conventions for creating,
  reading, labelling, and closing them, plus the wayfinder map/child/blocking operations.
- triage-labels.md — the canonical triage roles used to label incoming work.
- domain.md — how to consume the domain documentation (CONTEXT.md and docs/adr/) before exploring
  or changing the codebase, and when to reach for the domain-modeling skill.
