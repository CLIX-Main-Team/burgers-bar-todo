loop, the app-data tools, web search, source chips, the answer log and the evaluation harness.

- 03-roadmap.md: the ordered work list, with six lines for the owner at the top.
- 01-best-practices.md: the scorecard, thirteen lenses against 2026 practice, with sources.
- 02-implementation-audit.md: the findings behind the roadmap, each with a code reference.
