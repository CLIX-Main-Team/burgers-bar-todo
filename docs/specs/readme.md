# specs: design specifications

What was decided before a feature was built, and why. Each specification was written with the
owner before the code, and the feature shipped from it. The ADRs in `docs/adr/` hold the
architecture-level decisions; these hold the product-level ones.

- 2026-08-23-locations-redesign-design.md: the per-branch admin role and the branch detail page.
- 2026-08-28-project-step-owners-design.md: handing a project's checklist line to people.
- 2026-09-04-profile-page-design.md: the profile page (display name, avatar colour, password).
- 2026-09-20-departments-and-task-subjects-design.md: departments, and the task board opening on
  a department's subjects.
